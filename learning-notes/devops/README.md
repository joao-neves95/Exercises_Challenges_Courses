## Types of web hosting

- Shared
  - Economical option.
  - The provider shares resources of a single machine between multiple clients.
  - Limited administrative access.
- VPS
  - When a physical server is split up into several virtual machines, each one with the same resources that the original server had.
  - Each website has its own server space.
  - Root access; more control over the server configurations.
- Dedicated
  - Each client has its own server.
- Cloud
- Collocated
