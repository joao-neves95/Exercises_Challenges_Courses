# Computer Architecture

## Hardware

- CPU
- RAM
- Persistent memory (storage)

## Multithreading

- Each thread has a stack.
- A multithreaded environment can have deadlocks. Single-threaded environments try to fix these with strategies like an event loop.

## Memory Size

- 8 bits:
  - Numbers:
    - Unsigned: 0 to 255
    - Signed: -127 to 127
- 16 bits:
  - Numbers:
    - Unsigned: 0 to 65535
    - Signed: -32768 to 32767
- 32 bits:
  - Numbers:
    - Unsigned: 0 to 4294967295
    - Signed: -2147483648 to 2147483647
- 62 bits:
  - Numbers:
    - Unsigned: 0 to 18446744073709551615
    - Signed: -9223372036854775808 to 9223372036854775807
